# Quiz Application (Java Console-Based)

A simple console-based Quiz Application built using Java.
The application presents multiple-choice questions to the user, evaluates responses, and displays the final score.

---

## Features

* Multiple-choice questions
* User input for selecting answers
* Instant feedback for each question
* Final score calculation
* Console-based interaction

---

## Technologies Used

* Java (Core Java)
* Object-Oriented Programming (OOP)
* Java Collections (ArrayList)
* Scanner class for user input

---

## Project Structure

QuizApplication.java

Classes included:

* Question
  Stores question text, options, and the correct answer

* Quiz
  Handles quiz logic such as adding questions, running the quiz, and displaying results

* QuizApplication
  Main class used to execute the program

---

## How to Run

1. Clone the repository:
   git clone https://github.com/your-username/quiz-application.git

2. Navigate to the project directory:
   cd quiz-application

3. Compile the program:
   javac QuizApplication.java

4. Run the program:
   java QuizApplication
